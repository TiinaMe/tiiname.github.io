19 · Kuvagalleria ja lightbox

  • Etusivu
  • CSS-esimerkit

Klikkaa pikkukuvaa: se avautuu koko ruutuun. Katso osoiteriviä: perään tulee #kuva-2. Selaimen Takaisin-nappi sulkee kuvan, koska jokainen avaus on oma osoite. Ei riviäkään JavaScriptiä.

Miten tämä toimii

  1. <a href="#kuva-2"> on tavallinen ankkurilinkki. Klikkaus muuttaa osoitteen loppuosan (fragmentin).
  2. Elementti, jonka id vastaa fragmenttia, saa :target-pseudoluokan. .lightbox:target { display: grid } näyttää sen.
  3. position: fixed; inset: 0 peittää koko näkymän. z-index: 100 nostaa sen navin (10) yläpuolelle.
  4. Sulje-, edellinen- ja seuraava-painikkeet ovat linkkejä toisiin fragmentteihin. Takaisin-nappi toimii, koska selain muistaa fragmentit historiassa.
  5. Näppäimistö: Tab siirtyy pikkukuvasta toiseen, Enter avaa, Tab lightboxin sisällä löytää Sulje-linkin.

Rajat ja JavaScript-kurssin jatko

  • Esc-näppäin ei sulje: CSS ei kuule näppäimiä. JS:llä keydown + location.hash = "".
  • Isot kuvat ladataan sivun mukana, vaikka niitä ei avattaisi. Neljällä kuvalla ei haittaa, neljälläkymmenellä haittaa. JS lataa tarvittaessa.
  • Sivu hyppää ankkuriin, jos lightbox ei olisi fixed. Nyt ei hyppää, koska fixed-elementillä ei ole paikkaa virrassa.

Kokeile

  • Vaihda display: none → opacity: 0; pointer-events: none ja :targetiin opacity: 1 + transition. Pehmeä häivytys, mutta mitä tapahtuu Tab-näppäimelle?
  • Lisää viides kuva. Montako kohtaa HTML:ssä pitää muuttaa? (Vastaus: pikkukuva, uusi figure ja kahden naapurin edellinen/seuraava-linkit.)
  • Poista aspect-ratio pikkukuvista ja katso, mitä eri kokoisille kuville tapahtuu.
