Kun useampi sääntö osuu samaan elementtiin, selain päättää voittajan kolmessa vaiheessa: 1. tärkeys (!important ja alkuperä) → 2. spesifisyys (kuinka tarkka valitsin) → 3. järjestys (myöhempi voittaa).

A · Sama spesifisyys: viimeinen voittaa

Tämä on punainen, vaikka ensimmäinen sääntö sanoi vihreä.

.a-teksti { color: green; }
.a-teksti { color: #B00020; }  /* voittaa */

B · Spesifisyys: tarkempi voittaa

Oranssi: p.b-luokka (0,1,1) voittaa .b-luokka:n (0,1,0). .demo-b p on myös 0,1,1 mutta aiempi, joten häviää järjestyksessä.

Sininen: id (1,0,0) voittaa kaikki luokat, vaikka olisi kirjoitettu ensimmäisenä.

Vertaa vasemmalta oikealle: 1,0,0 voittaa aina 0,99,99.

C · Periytyminen

Tämän laatikon teksti on sinistä ja Georgia-fonttia, koska color ja font-family periytyvät vanhemmalta. Reuna ja padding eivät periydy: tällä kappaleella ei ole keltaista reunaa, vain laatikolla.

Linkki perii värin, koska sille on annettu color: inherit. Ilman sitä se olisi selaimen oletussininen.

Periytyvät: color, font-*, line-height, text-align, list-style. Eivät periydy: margin, padding, border, background, width, height, display.

D · !important

Vihreä, vaikka id-sääntö sanoo punainen. !important ohittaa spesifisyyden.

Ongelma: ainoa tapa ohittaa !important on toinen !important, ja pian kukaan ei tiedä, mikä voittaa. Jos tarvitset sitä, valitsin on luultavasti liian epätarkka. Korjaa valitsin.

Mistä näet, mikä sääntö voitti?

F12 → Elements → valitse elementti → Styles. Säännöt ovat voittajajärjestyksessä ylhäältä alas, hävinneet arvot yliviivattuina. Oikealla lukee tiedosto ja rivinumero. Computed-välilehti näyttää lopullisen arvon ja sen lähteen.
