Kolme korttia

Luentoesimerkki: säiliö + kolme korttia. Avaa 14-kolme-korttia.css viereen (Ctrl+U → linkki). Kavenna ikkunaa: kortit putoavat allekkain ilman media queryä.

Juniorit

Harjoitukset tiistaisin ja torstaisin klo 17–18.30. Aloittelijat tervetulleita, välineitä saa lainaksi.

Lue lisää

Edustus

Kotiottelut lauantaisin. Tämä teksti on pidempi kuin muissa korteissa, jotta näet, että napit pysyvät silti samalla korkeudella.

Otteluohjelma

Yhteystiedot

Kuopion jäähalli, Kaartokatu 6.

Ota yhteyttä

Mitä tässä tapahtuu

  1. .kortit { display: flex; gap: 24px; flex-wrap: wrap; } – kolme lasta riviin, väli väliin, rivitys kun ei mahdu.
  2. .kortti { flex: 1 1 250px; } – jokainen kortti kasvaa ja kutistuu, lähtöleveys 250 px. Tämä yksi rivi tekee responsiivisuuden.
  3. .kortti { display: flex; flex-direction: column; } – kortin sisällä flex pystysuuntaan.
  4. .kortti a { margin-top: auto; } – nappi työntyy alareunaan, vaikka tekstit ovat eri pituisia.
  5. img { object-fit: cover; height: 160px; } – kaikki kuvat saman korkuisia, rajataan eikä venytetä.

Kokeile

  • Poista flex-wrap: wrap ja kavenna ikkunaa.
  • Vaihda flex: 1 1 250px → flex: 0 0 250px. Mitä tapahtuu leveällä ruudulla?
  • Poista margin-top: auto napista.
  • Poista flex-grow: 1 .sisalto-säännöstä.
  • Lisää neljäs kortti HTML:ään. Tarvitseeko CSS:ää muuttaa?
