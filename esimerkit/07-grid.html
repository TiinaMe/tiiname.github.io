Grid asettelee kahdessa suunnassa: rivit ja palstat yhtä aikaa. Flexbox on yhdelle riville (valikko, kortin sisältö), grid koko sivulle ja ruudukoille. F12 → Elements → grid-merkki näyttää viivat ja numerot.

Lapset täyttävät solut järjestyksessä ja rivittyvät itsestään. fr = osuus (fraction) vapaasta tilasta.

5 · grid-template-areas: koko sivun pohja

header

nav

main

aside

footer

body {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-areas:
    "header header"
    "nav    main"
    "nav    aside"
    "footer footer";
}
header { grid-area: header; }  nav { grid-area: nav; }  /* jne. */

@media (max-width: 600px) {
  body { grid-template-columns: 1fr;
         grid-template-areas: "header" "nav" "main" "aside" "footer"; }
}

Kavenna ikkunaa alle 600 px: sama HTML, uusi kartta, kaikki allekkain. Aluekartta on kuin ASCII-piirros sivusta, ja sen voi lukea suoraan.

Flex vai grid?

TilanneKäytä
Valikko, painikerivi, logo + otsikko, kortin sisäinen riviFlexbox
Korttiruudukko, kuvagalleria, tuotelistaGrid (auto-fit + minmax)
Koko sivun pohja: header, sivupalkki, sisältö, footerGrid (template-areas)
Yhden asian keskitysKumpi vain: flex + center + center, tai grid + place-items: center
Lomake: label ja kenttä vierekkäinGrid (2 palstaa) tai flex per rivi
