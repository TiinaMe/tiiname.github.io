08 · Responsiivisuus

Responsiivinen sivu mukautuu näytön leveyteen. Työkalut: viewport-meta, joustavat yksiköt, flex/grid ja media queryt. Avaa F12 → laitetila (Ctrl+Shift+M) ja vedä leveyttä: seuraa, miten alla oleva muuttuu.

1 · Mikä leveys on voimassa?

@media (min-width: 600px)  { … }   /* tästä ylöspäin */
@media (min-width: 900px)  { … }
@media (min-width: 1200px) { … }

Kuusi

Kirjoita ensin puhelimen tyylit ilman media queryä. Lisää min-width-säännöillä vain se, mikä muuttuu isommalla. Puhelin lataa vähiten CSS:ää ja saat yksinkertaisimman version ensin valmiiksi.

4 · Näytä tai piilota leveyden mukaan

📱 Tämä näkyy vain alle 900 px. Esim. lyhyt yhteystietorivi.

🖥 Tämä näkyy vain 900 px ja yli. Esim. sivupalkin lisätiedot.

Käytä säästeliäästi: piilotettu sisältö ladataan silti. Älä piilota mitään tärkeää puhelimelta.

5 · Sujuva otsikko clamp()-funktiolla

Tämä otsikko skaalautuu

font-size: clamp(1.5rem, 1rem + 3vw, 3.5rem);
/*           min    toivottu (kasvaa ikkunan mukana)  max */

6 · Kuva ja taulukko eivät vuoda yli

img { max-width: 100%; height: auto; } kutistaa kuvan säiliön levyiseksi. Tämä on jo tyyli.css:ssä.

7 · Media queryt käyttäjän asetuksille

prefers-color-scheme:

prefers-reduced-motion:

orientation:

hover:

Kokeile DevToolsin Rendering-paneelista (oppitunti 2): emuloi tumma tila ja katso, miten rivi muuttuu.

Yleiset raja-arvot

Ei ole oikeita lukuja: valitse rajat siitä, missä oma asettelusi alkaa näyttää huonolta. Hyvä lähtökohta: 600px (puhelin → tabletti), 900px (tabletti → työpöytä), 1200px (leveä). Käytä em-yksikköä media queryissä (37.5em = 600 px), niin raja seuraa käyttäjän fonttikokoa.
