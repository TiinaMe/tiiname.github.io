Näin käytät tätä sivua

Tällä sivulla on jokainen HTML-elementti, jolle css/tyyli.css antaa tyylin. Sivulla itsellään ei ole yhtään CSS-riviä. Avaa tyyli.css VS Codeen tämän sivun viereen (Live Server päällä), etsi Ctrl+F sanalla KOKEILE ja tee mitä kommentti ehdottaa. Tallenna ja katso, mikä täällä muuttui.

Kymmenen kokeilua, järjestyksessä

  1. Värit: vaihda :root-lohkossa --vari-paa ja --vari-korostus. Laske, kuinka monessa paikassa sivu muuttui.
  2. Riviväli: body { line-height } arvoon 1.0, sitten 2.0. Lue tekstikappale molemmilla. Palauta 1.6.
  3. Palstan leveys: kommentoi pois sääntö p, li, dd … { max-width }. Levennä ikkuna. Lue kappale. Palauta.
  4. Pyöristys: --kulma: 0, sitten 16px. Katso painikkeet, kortit, kentät, kuvat.
  5. Välit: --vali: 0.5rem, sitten 2rem. Koko sivu tiivistyy tai väljenee.
  6. Fontti: hae Google Fontsista yksi fontti, lisää link head-osaan ja vaihda --fontti-otsikko. Vain otsikot vaihtuvat.
  7. Navigointi: poista nav ul { display: flex }. Valikko menee pystyyn. Palauta ja kokeile justify-content: center.
  8. Taulukko: vaihda tbody tr:nth-child(even) → odd, sitten 3n. Vaihda border-collapse: separate ja lisää border-spacing: 4px.
  9. Painike: button { border-radius: 999px } ja hover-tilaan transform: scale(1.05). Vie hiiri päälle.
  10. Tumma tila: DevTools → ⋮ → More tools → Rendering → Emulate CSS prefers-color-scheme: dark. Etsi elementti, joka näyttää väärältä, ja korjaa se tumman tilan osioon.

Sääntö: yksi muutos kerrallaan, tallenna, katso. Jos et näe muutosta, tarkista DevToolsista (F12 → Elements → Styles), osuuko sääntö ja hävisikö se toiselle.
