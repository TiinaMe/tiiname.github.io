Jääkiekkoa junioreille Kuopiossa

Kolme sivua, yksi header, yksi nav, yksi footer. Kavenna ikkunaa alle 640 px: valikko muuttuu napiksi. Ei JavaScriptiä.

Katso joukkueet

Mitä tässä esimerkissä on

Hampurilaisvalikko

Piilotettu checkbox + label. nav:has(:checked) ul näyttää listan. Toimii vain kapealla ruudulla: media query hoitaa vaihdon.

Murupolku

Alasivuilla nav aria-label="Murupolku" + numeroitu lista. Erottimet tulevat li + li::before -säännöllä, ei HTML:stä.

Footer kolmella palstalla

grid-template-columns: repeat(auto-fit, minmax(14rem, 1fr)): kolme palstaa leveällä, yksi kapealla, ei media querya.

Näin kopioit tämän omaan projektiisi

  1. Kopioi sivusto.css repon juureen kansioon css/ ja linkitä se tyyli.css:n jälkeen.
  2. Kopioi <header>, <nav> ja <footer> tältä sivulta omiin sivuihisi. Korjaa polut: juuressa css/tyyli.css ja img/…, ei ../../.
  3. Vaihda aria-current="page" sille linkille, joka on kyseinen sivu.
  4. Lisää murupolku alasivuille, ei etusivulle.

Sama header kolmessa tiedostossa tuntuu toistolta. Se on tarkoitus: JavaScript-kurssilla opit, miten yhteiset osat ladataan yhdestä paikasta.
