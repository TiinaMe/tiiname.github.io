Erikokoiset kortit: mikä päättää korkeuden?

Sama kolmen kortin rivi seitsemän kertaa. Korttien HTML ja CSS ovat identtiset. Ainoa ero on säiliön align-items (ja kohdissa E–F yksi lisärivi). Katkoviiva on säiliön reuna.

Vastaus kysymykseen "miten kortit saadaan alkamaan yläreunasta": .kortit { align-items: flex-start; } (rivi B). Oletus on stretch, joka venyttää kaikki rivin kortit korkeimman mukaan, ja siksi ilman asetusta ne näyttävät samankorkuisilta.

A · (ei asetusta) = align-items: stretch

Tämä kortti on pisin. Siinä on useampi kappale, jotta korkeusero näkyy varmasti.

Muistisääntö

  • justify-content = pääakseli (rivissä vaaka): mihin kortit asettuvat vasen–oikea.
  • align-items = poikkiakseli (rivissä pysty): mihin kortit asettuvat ylä–ala ja venyvätkö ne.
  • align-self = sama yhdelle lapselle, voittaa säiliön align-items-asetuksen.
  • Gridissä arvot ovat start / center / end / stretch ilman flex--etuliitettä.

Kokeile

  • Avaa F12 → Elements, valitse rivin A .kortit ja lisää Styles-paneeliin align-items: flex-start. Vaihda arvoa nuolinäppäimillä.
  • Kavenna ikkunaa, kunnes kortit rivittyvät. Huomaa: align-items toimii rivi kerrallaan, joten alemman rivin kortit tasautuvat omaan riviinsä.
  • Rivissä F poista margin-top: auto. Mihin napit menevät?
  • Kopioi rivin B pitkään korttiin kuusi <p>-kappaletta lisää. Rikkoutuuko seuraavien rivien järjestys? Ei: jokainen .kortit on tavallinen lohko, jonka korkeus kasvaa sisällön mukaan, ja seuraava alkaa siitä mihin edellinen päättyi. Flex vaikuttaa vain säiliön sisällä.
  • Lisää sitten .kortit { height: 300px; } ja katso uudestaan: nyt sisältö pursuaa säiliön yli seuraavan rivin päälle, koska overflow on oletuksena visible. Kiinteä height on yleisin syy "päällekkäin meneviin" elementteihin. Jos tarvitset vähimmäiskorkeuden, käytä min-height.
