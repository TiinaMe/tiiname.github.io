01 · Kolme tapaa liittää CSS

  • Kaikki esimerkit
  • Seuraava →

Sama sivu käyttää kaikkia kolmea tapaa. Paina Ctrl+U ja etsi ne.

Tapa 1 · Inline-tyyli (style-attribuutti)

Tämä kappale on punainen ja lihavoitu inline-tyylillä.

<p style="color: #B00020; font-weight: bold;">…</p>

Miinukset: toistuu joka elementissä, ei voi käyttää uudelleen, sekoittaa sisällön ja ulkoasun.

Tapa 2 · style-lohko head-osassa

Tämän laatikon katkoviivareuna tulee <style>-lohkosta sivun head-osasta.

<head>
  <style>
    .esimerkki { border: 2px dashed #3A5696; padding: 1rem; }
  </style>
</head>

Plussat: yksi paikka per sivu. Miinukset: ei jaeta muiden sivujen kanssa, pitää kopioida joka sivulle.

Tapa 3 · Ulkoinen tiedosto (suositus)

Fontti, värit, header, nav ja footer tulevat tiedostosta css/tyyli.css. Sama tiedosto on käytössä kaikilla sivuston sivuilla.

<head>
  <link rel="stylesheet" href="css/tyyli.css">
</head>

Plussat: yksi muutos näkyy kaikkialla, selain tallentaa tiedoston välimuistiin, HTML pysyy puhtaana. Tämä on kurssin päätapa.

CSS-säännön anatomia

valitsin {
  ominaisuus: arvo;
  ominaisuus: arvo;
}

/* esimerkki */
h2 {
  color: #3A5696;
  font-size: 2rem;
}
  • Valitsin kertoo, mihin elementteihin sääntö osuu.
  • Ominaisuus (property) on se, mitä muutetaan: väri, koko, marginaali.
  • Arvo on uusi asetus. Puolipiste päättää jokaisen parin.
  • /* kommentti */ ei vaikuta mihinkään. Kirjoita niitä itsellesi.

Kokeile itse

  1. F12 → Elements → valitse tämän sivun h1 → Styles-paneelissa näet, mistä tiedostosta ja riviltä väri tulee.
  2. Klikkaa väriä ja vaihda se. Muutos näkyy heti, katoaa päivityksessä.
  3. Avaa css/tyyli.css VS Codessa, vaihda --vari-paa ja tallenna. Kaikki sivut vaihtuvat.
