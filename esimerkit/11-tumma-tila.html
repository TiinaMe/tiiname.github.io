11 · Tumma tila CSS-muuttujilla

Nyt käytössä: . Vaihda käyttöjärjestelmän teema tai emuloi DevToolsissa: ⋮ → More tools → Rendering → Emulate CSS prefers-color-scheme.

Miten tämä toimii

  1. Jokainen väri on muuttuja :root-osiossa: --tausta, --pinta, --teksti…
  2. @media (prefers-color-scheme: dark) määrittelee samat muuttujat uudestaan tummilla arvoilla.
  3. Kaikki säännöt käyttävät var(--nimi). Niitä ei tarvitse koskea.
  4. <meta name="color-scheme" content="light dark"> vaihtaa myös selaimen omat osat: vierityspalkit, lomakekentät, valintalistat.

Käyttäjän oma valinta

Jos haluat vaihtopainikkeen sivulle, se vaatii kolme riviä JavaScriptiä (seuraava kurssi):

document.documentElement.dataset.theme = "dark";   // tai "light"

CSS on jo valmis: :root[data-theme="dark"] -sääntö odottaa attribuuttia. Kokeile nyt DevToolsissa: Elements → valitse <html> → kaksoisklikkaa ja lisää data-theme="dark".

Muistettavaa

  • Älä vain käännä värejä: tumma tila tarvitsee vaaleamman korostusvärin, jotta kontrasti 4,5:1 säilyy. Tarkista DevToolsin värivalitsimella.
  • Puhdas musta tausta (#000) ja puhdas valkoinen teksti (#fff) väsyttävät. Käytä tummanharmaata ja luonnonvalkoista.
  • Himmennä kuvia hieman (filter: brightness(0.85)).
  • Testaa molemmat tilat ennen palautusta.
