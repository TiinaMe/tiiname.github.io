Jokainen HTML-elementti on suorakulmainen laatikko, jossa on neljä kerrosta: sisältö (content), täyte (padding), reuna (border) ja marginaali (margin). Avaa F12 → Elements → Computed ja katso laatikkomallikuvaa valitessasi alla olevia laatikoita.

content-box (oletus): width = sisältö

width: 300px + padding 20 + border 10 molemmin puolin = 360 px leveä

border-box: width = sisältö + padding + reuna

Sama CSS, mutta box-sizing: border-box → 300 px leveä. Sisällölle jää 240 px.

Siksi tyyli.css alkaa säännöllä *, *::before, *::after { box-sizing: border-box; }. Leveydet tarkoittavat sitä, miltä ne näyttävät.

Lyhennemerkintä: kellon suuntaan ylhäältä

padding: 10px 20px 30px 40px → ylä 10, oikea 20, ala 30, vasen 40

padding: 10px;                 /* kaikki neljä */
padding: 10px 20px;            /* ylä+ala 10, vasen+oikea 20 */
padding: 10px 20px 30px;       /* ylä 10, sivut 20, ala 30 */
padding: 10px 20px 30px 40px;  /* ylä oikea ala vasen */
padding-left: 40px;            /* yksi sivu */
padding-inline: 20px;          /* vasen+oikea (looginen) */
padding-block: 10px;           /* ylä+ala */

Marginaalit yhdistyvät pystysuunnassa

Tällä on margin 24px ylä ja ala.

Tälläkin. Väliin jää silti vain 24 px, ei 48: pystymarginaaleista suurempi voittaa. Vaakamarginaalit eivät yhdisty.

Keskitys: margin: 0 auto

60 % leveä, keskellä. Toimii, kun elementillä on width ja se on block.

display: inline, inline-block, block

Teksti inline: padding ei työnnä rivejä jatkuu samalla rivillä inline-block: width toimii ja jatkuu.

block: oma rivi, width toimii

Oletuksena div, p, h1, ul, section ovat block ja a, span, strong, img inline. Flexbox ja grid (seuraavat esimerkit) ovat display-arvoja nekin.

Muista

  • Tausta täyttää sisällön ja paddingin, ei marginaalia.
  • Marginaali on aina läpinäkyvä: sen läpi näkyy vanhemman tausta.
  • margin: auto keskittää, padding antaa tekstille ilmaa, gap (flex/grid) antaa väliä sisarusten väliin ilman marginaaleja.
